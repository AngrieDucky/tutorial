Задача 1: Регистрация и авторизация	
	
	Сделать систему регистрации и авторизации.
	
	Что делаем:
	1. Создаём в БД нужные таблицы (users, applications, courses, другое при необходимости).
	2. Создаём классы моделей SQLAlchemy.
	3. Делаем формы для регистрации и авторизации (логин, хеш пароля, фио, телефон, почта).
	4. Создаём роут для логина юзера и отдельный для регистрации.
	5. Создаём страницу, на которую редиректим юзера после авторизации. На странице должны быть заявки юзера из таблицы applications.
	
Задача 2: Администрирование заявок	
	
	Сделать админский доступ для изменения статуса заявок.
	
	Что делаем:
	1. Создаём в БД нужные таблицы (users, applications, courses, другое при необходимости).
	2. Создаём классы моделей SQLAlchemy.
	3. Создаём супер-пользователя с логином Admin.
	4. Создём роут для супер-пользователя, где будет выводиться заявки пользователя.
	5. Делаем в роуте проверку на то, является ли пользователь админом. И редирект на страницу пользователя, если нет.
	6. Создём у админа на странице возможность менять следующие параметры заявки: форму оплаты, статус.
	
Задача 3: Система отзывов	
	
	Сделать систему отзывов только от пользователей, которые подали заяки.
	
	Что делаем:
	1. Создаём в БД нужные таблицы (users, applications, courses, другое при необходимости)
	2. Создаём классы моделей SQLAlchemy.
	3. Делаем отдельный роут, в котором будет более подробное описание курса и имеющиеся отзывы.
	4. Делаем возможность залогиненному юзеру оставить отзыв.
	5. Добавляем проверку, подана ли заявка от юзера, который оставляет отзыв на этот курс.
	6. Обрабатываем ошибку от бэка, если пользователь не подавал заявку.
